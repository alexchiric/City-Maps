# City-Maps web

Next.js (App Router) + TypeScript + Tailwind + MapLibre GL frontend for the
livability map. Reads `public/data/pois.geojson` and `public/data/scores.geojson`
at runtime — no Python, no backend call. Those files are generated by the
pipeline in the repo root (`python -m pipeline.run`), which also copies them
in here; see the root `README.md`.

If `public/data/*.geojson` is missing (a fresh clone before the pipeline has
run once), the map loads with no data — run the pipeline from the repo root
first.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploying to Vercel

This folder is self-contained, so it deploys independently of the rest of
the repo:

1. In the Vercel project settings, set **Root Directory** to `web/`.
2. Build command: `next build` (the default — no override needed).
3. No environment variables are required for the default GeoJSON-only setup.

Since `public/data/*.geojson` is gitignored (regenerated by the pipeline, not
checked in), make sure it's committed for whatever branch Vercel deploys —
either commit a snapshot of the generated files, or add a build step that
runs the pipeline before `next build`.
